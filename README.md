# 小灰桌宠 v2

这是基于 PyQt5 的桌面陪伴程序，已经切换到 Codex Pet v2 图集。

小灰来自游戏《群星》（Stellaris）。

## 运行

在项目目录执行：

```powershell
python main.py
```

需要：

- Python 3.10+
- PyQt5
- requests

## 交互

- 左键拖动小灰
- 单击：触摸反馈
- 双击：打开聊天
- 右键：打开白色极简菜单
- 小灰会根据鼠标所在方向切换 16 个视线方向
- 番茄钟运行时自动使用专注状态动画

## GUI

界面采用白底、黑字、细边框、轻阴影和极简留白风格，聊天、历史记录、API 设置和番茄钟面板保持统一视觉。
